# Мини-парсер объявлений Avito

Парсер ищет объявления на [Avito.ru](https://www.avito.ru) по заданным артикулам
и сохраняет 5 самых дешёвых подходящих объявлений в CSV-файл.

## Быстрый старт

```bash
# 1. Создать виртуальное окружение (рекомендуется)
python3 -m venv .venv
source .venv/bin/activate    # Linux / macOS
# .venv\Scripts\activate     # Windows

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить парсер
python -m avito_parser
```

Результат сохраняется в **`result.csv`** (кодировка UTF-8 с BOM, разделитель `,`).

## Требования

- Python 3.10+
- `requests` — для HTTP-запросов к API Avito

Список зависимостей: [`requirements.txt`](requirements.txt)

## Выбор подхода

При изучении Avito было обнаружено, что внутренний эндпоинт
`/web/1/js/items` возвращает чистый JSON с полными данными объявлений
(цена, город, параметры запчастей и т.д.) в ответ на простой GET-запрос.

**Почему JSON-API, а не парсинг HTML:**

- **Стабильность** — структура JSON API значительно устойчивее, чем DOM-структура
  HTML-страницы, которая может меняться при обновлении фронтенда.
- **Полнота данных** — в JSON API доступны машиночитаемые поля: числовая цена,
  структурированные параметры запчастей (`SparePartsParamsStep`), координаты,
  рейтинг — всё без необходимости извлечения из вёрстки.
- **Производительность** — один GET-запрос с компактным JSON вместо загрузки
  полной HTML-страницы с JS/CSS/картинками.
- **Простота** — не требуется headless-браузер (Playwright/Selenium) для
  рендеринга JavaScript-контента.

## Принцип работы

1. Парсер делает GET-запрос к API поиска Avito
   (`https://www.avito.ru/web/1/js/items`) и получает JSON с результатами.
2. Если запрос неудачен (ошибка сети, HTTP 4xx/5xx), парсер повторяет
   попытку до 3 раз с экспоненциальной задержкой (5 → 10 → 20 сек.).
3. Если все попытки провалены — подставляет тестовые данные из [`mock_data/`](mock_data/).
4. Из полученных данных отфильтровываются объявления, содержащие искомый
   артикул в параметре `SparePartsParamsStep` (для точного соответствия).
5. Объявления без цены исключаются, дубликаты удаляются, результат
   сортируется по возрастанию цены.
6. Берутся 5 самых дешёвых объявлений (или все, если найдено меньше).

## Как задаются параметры поиска

| Параметр | Значение | Где задаётся |
|----------|----------|--------------|
| **Регион** | Москва и МО (`locationId=107620`) | [`config.py`](avito_parser/config.py) |
| **Состояние товара** | Только новое (`params[110056][0]=418153`) | [`config.py`](avito_parser/config.py) |
| **Сортировка по цене** | По возрастанию (`sort=1`) | Параметр `sort` в [`api.py`](avito_parser/api.py) |
| **Кол-во на артикул** | 5 самых дешёвых | [`config.py`](avito_parser/config.py) |

## Артикулы для поиска

Задаются в списке [`ARTICLES`](avito_parser/config.py) в файле [`config.py`](avito_parser/config.py):

```python
ARTICLES = [
    {"article": "21830S1400", "description": "Кронштейн КПП в сборе"},
    {"article": "244203A000", "description": "Натяжитель цепи масляного насоса"},
]
```

Для добавления новых артикулов — просто допишите строки в этот список.

## Формат результата

CSV-файл `result.csv` со следующими колонками:

| Колонка | Описание |
|---------|----------|
| Артикул | Искомый артикул |
| Поисковый запрос | Текст поискового запроса |
| Заголовок | Название объявления |
| Цена (руб.) | Цена числом |
| Город/Регион | Город или населённый пункт |
| Состояние товара | «Новое» |
| Ссылка | Полный URL объявления |
| Место по цене | Позиция в отсортированном списке (1 = самое дешёвое) |
| Дата и время проверки | Время выполнения запроса (UTC+8) |

Если по артикулу ничего не найдено или запрос не удался — в таблицу
добавляется строка с соответствующим статусом («ОШИБКА» или «НЕ НАЙДЕНО»).
